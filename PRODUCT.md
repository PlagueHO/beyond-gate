# Beyond Gate documentation

<!-- impeccable:product-schema 1 -->

## Platform

web

This record applies to the documentation website only.
Beyond Gate remains a native Rust CLI and local stdio MCP server.

## Users

CLI and MCP users come first. They need installation instructions, command
and tool references, authentication guidance, and clear current limits.
Contributors need a separate route to architecture, testing, and development.

## Product Purpose

Make existing Beyond Gate documentation easy to find, read, and search.
Use the existing Markdown references as the source, not a second set of contracts.

## Capabilities and Constraints

- Keep Node.js and pnpm development-only.
- Keep account access, live testing, publishing, and repository settings out of scope.
- Distinguish implemented, synthetic-tested, live-verified, unsupported, and unverified behavior.
- Keep source links and offline Markdown checks working.
- Provide responsive navigation, local search, and keyboard access.

## Brand Commitments

Use the Beyond Gate logo and gate icons in `assets`.
Keep their red, white, and black color identity.
The user requests a fantasy feel related to D&D Beyond, without copied branding or artwork.
Use readable sentence-case text and solid outlines.

## Evidence on Hand

Existing guides are in `docs`. CLI and MCP references are `docs/cli.md` and `docs/mcp.md`.
The original logo is `assets/beyond-gate-logo.png`.
Gate icons are in `assets/icons`.
No proprietary artwork, account snapshots, or new capability claims are needed.

## Theme Review

The user requested five working browser theme previews.
Each must show the overview and the same long reference page.
Further discussion and refinement continue until the user approves a theme.
Gatehouse is the default selected during the later request for autonomous completion.
This is not an explicit visual approval. Keep the five samples in a separate
comparison build for later review.
